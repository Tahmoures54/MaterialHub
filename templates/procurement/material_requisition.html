Help - Using Material Requisitions

Material Requisitions in 3 simple actions

Create the request, review it, then let the workflow take over.

01Create

Click New MR and follow the short wizard. You only enter the information needed to start procurement.

02Review

Check the material, quantity and required date. You can add another material before creating the MR.

03Manage

Use the MR number for the report. Engineering can edit or delete; Project Management can approve or reject.

Excel import

If you already have a list, choose Import Excel from the New MR wizard. The first worksheet is previewed before creation.
