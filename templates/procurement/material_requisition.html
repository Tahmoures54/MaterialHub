Help - Using Material Requisitions

Welcome to the Material Requisitions Page!

This page helps you manage material requisitions for your projects. Here's a quick guide:

  • Create a New MR: Click "Create New MR" to open a form. Add multiple rows using "Add Row". Fill in the details and submit (Engineering only).
  • Manage an MR: Use the Edit/Delete buttons on each card to modify or remove requisitions (Engineering only).
  • Approve an MR: Project Managers can approve or reject MRs in each stage using the Approve button.
  • View Details: Click on an MR No link to open a detailed report in a new tab.
  • Filter by Discipline: Use the discipline dropdown to filter requisitions.
  • Search MRs: Use the search bar to find requisitions by MR No or Subject.
  • Import from CSV: Use the "Import from CSV" option in the Create modal to upload a CSV file (Engineering only).
  • Export to CSV: Click "Export to CSV" to download the requisitions as a CSV file.

If you encounter issues, check the browser console (F12 > Console) for errors or contact your system administrator.
