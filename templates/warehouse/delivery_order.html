Help - Using Delivery Order

Welcome to the Delivery Order Page!

This page helps you manage delivery orders for your projects. Here's a quick guide:

  • Create a New Delivery Order: Click "Create New Delivery Order" to open a form. Add multiple rows using "Add Row". Fill in the details and submit (Delivery only).
  • Manage a Delivery Order: Use the Edit/Delete buttons on each card to modify or remove orders (Delivery only).
  • Approve a Delivery Order: Project Managers can approve or reject orders using the Approve button.
  • Import from CSV: Use the "Import from CSV" option in the Create modal to upload a CSV file (Delivery only).
  • Export to CSV: Click "Export to CSV" to download the orders as a CSV file.

If you encounter issues, check the browser console (F12 > Console) for errors or contact your system administrator.
