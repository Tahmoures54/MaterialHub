Help - Using Quality Control

Welcome to the Quality Control Page!

This page helps you manage quality control inspections for your projects. Here's a quick guide:

  • Create a New Inspection: Click "Create New Inspection" to open a form. Add multiple rows using "Add Row". Fill in the details and submit (Quality Control only).
  • Manage an Inspection: Use the Edit/Delete buttons on each card to modify or remove inspections (Quality Control only).
  • Approve an Inspection: Project Managers can approve or reject inspections using the Approve button.
  • Import from CSV: Use the "Import from CSV" option in the Create modal to upload a CSV file (Quality Control only).
  • Export to CSV: Click "Export to CSV" to download the inspections as a CSV file.

If you encounter issues, check the browser console (F12 > Console) for errors or contact your system administrator.
