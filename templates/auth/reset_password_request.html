How to Set Up Microsoft Authenticator

Follow these steps to use the account recovery key we’ll send you to log in securely.

1

Check Your Email

We’ll send an account recovery key to your email (e.g., your@email.com). Check your inbox and spam/junk folders. The key may be a QR code, text code, or link.

Didn’t get the email? Resubmit your email above.

2

Install Microsoft Authenticator

Download and install the Microsoft Authenticator app to generate secure login codes.

  • Android: Get it from Google Play.
  • iOS: Get it from the App Store.

Open the app, accept the terms, and skip optional prompts like data sharing.

Already have the app? Ensure the MaterialHub account isn’t already added to avoid duplicates.

3

Add Your MaterialHub Account

Use the recovery key to add your account to Microsoft Authenticator:

  • QR Code: Tap + in the app, select “Scan a QR code,” and scan the code from your email.
  • Text Code: Tap +, choose “Enter code manually,” and input the code (e.g., XXXX-YYYY-ZZZZ). Name the account “MaterialHub.”
  • Link: Click the link in the email to add the account automatically.

Once added, you’ll see a 6-digit code (e.g., 123456) that changes every 30 seconds.

Trouble with the key? Double-check for typos or contact Support.

4

Log In to MaterialHub

Go to the Login page, enter your email, and submit.

When prompted, open Microsoft Authenticator, copy the 6-digit code for MaterialHub, and enter it. Act quickly, as the code expires every 30 seconds!

Code not working? Ensure your phone’s clock is set to automatic and try the next code.

5

Tips and Troubleshooting

  • Back Up Your Account: In Authenticator, go to Settings > Cloud Backup, and sign in with a Microsoft account (e.g., Outlook). This protects your account if you lose your phone.
  • No Email Received: Resubmit your email above or check spam/junk.
  • Code Issues: Verify your phone’s clock is synced. If issues persist, contact Support.
  • Need Help?: Visit our Help Center or Contact Support.

Microsoft Authenticator keeps your account secure with codes that refresh every 30 seconds.
